# Assignment 2 Code Review

This folder contains the completed notebook, a runnable Python script, the input data, and recorded results.

## Run

Install NumPy, pandas, Matplotlib, and the scikit learn library. From this folder run

```bash
python Assignment2.py
```

The script reads `Advertising.csv` beside the Python file. The notebook contains the saved cell outputs.

## Results

The script writes `results/results.txt` with the regression coefficients, test R2 and RMSE values, PCA output dimensions, and variance ratios. It also saves plots of sample digits, reconstructions, the PCA projection, explained variance, and eigen digits in the `results` folder.
