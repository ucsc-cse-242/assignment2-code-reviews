# Assignment 2 — Nithin

Open [Assignment2.ipynb](Assignment2.ipynb) for the executed solutions, figures,
and complete code for MLE/posterior estimation, linear regression, and PCA.
The advertising dataset is included; the digits dataset comes with scikit-learn.

## Run

Python 3.13 was used for verification. From this repository folder:

```sh
python -m pip install -r requirements.txt
python -m jupyter lab Assignment2.ipynb
```

Select the Python 3 kernel, then restart the kernel and run all cells.
The train/test split and Gaussian noise use seed 242. The notebook includes
checks for matched train/test splits, regression coefficients against independent
least squares, PCA eigenvalues against SVD, and reconstruction behavior.
